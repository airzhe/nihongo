【〜ところだ】
意味：正好要...
接続：動詞辞書形
例文：いま行くところだ。 / これから食事にするところだ。

【〜ているところだ】
意味：正在...
接続：動詞ている形
例文：今読んでいるところだ。 / 娘は餃子を作っているところだ。

【〜たところだ】
意味：刚刚...
接続：動詞た形
語感：~たばかり侧重说话者的心理感觉，~たところだ侧重动作或事实刚刚完成。
例文：今帰ってきたところです。 / 終わったところです。

【〜ところに】
意味：正...的时候，...（发生了某事）
接続：動詞辞書形・ている形・た形
例文：新聞を読もうとしたところに、電話がかかってきた。 / 私が出かけるところに、彼が来た。

【〜ところへ】
意味：正...的时候，...
接続：動詞辞書形・ている形
語感：某人/某物向主语方向移动。
例文：どうしたらいいかと迷っているところへ、彼がやってきました。 / 出かけようとしているところへ、友達が来た。

【〜ところを】
意味：1. 正...的时候，... 2. 在...之时
接続：動詞辞書形・ている形・た形 / 連体形、名詞＋の
語感：1. 表示被发现或打扰等不利情况。 2. 用于寒暄，表示感谢或歉意。
例文：授業でスマホを使っているところを先生に見られてしまった。 / こっそりお酒を飲んでいたところを、彼女に見つかった。 / お忙しいところを失礼します。

【〜最中だ】
意味：正在...的时候
接続：動詞ている形、名詞＋の
語感：在最关键或高潮的时刻。
例文：今は会議の最中だ。 / スピーチの最中に、電話が鳴った。

【〜たびに】
意味：每当...
接続：動詞辞書形、名詞＋の
例文：この写真を見るたびに、大学時代を思い出す。 / あの人は来るたびに、文句を言う。

【〜ついでに】
意味：...的时候，顺便...
接続：動詞辞書形・た形、名詞＋の
例文：散歩のついでに、買い物をしてきた。 / 銀行に行くついでに、手紙を出す。

【〜うちに】
意味：1. 趁着... 2. 在...的过程中
接続：動詞辞書形・ている形・ない形、い/な形容詞、名詞＋の / 動詞辞書形・ている形・ない形
語感：1. 在某个状态发生变化前。 2. 发生了意想不到的自然变化。
例文：温かいうちに食べてください。 / 若いうちにしっかり勉強しなさい。 / 話しているうちに外は暗くなりました。 / 本を読んでいるうちに、眠くなった。

【〜か〜ないかのうちに】
意味：刚一...就...
接続：動詞辞書形＋か＋動詞ない形＋か
語感：前一个动作几乎未完成。
例文：一つの仕事が終わるか終わらないかのうちに、次の仕事が来た。 / ベルが鳴るか鳴らないかのうちに、彼は教室を飛び出した。

【〜かと思うと / 〜かと思ったら】
意味：原以为...却...；刚一...就...
接続：動詞た形、普通形
語感：表示出乎意料。
例文：雨が降ったかと思うと、すぐやんだ。 / 花が咲いたかと思うと、もう散ってしまった。 / 彼はもう北京へ行ったかと思ったら、まだ行かないでいた。

【〜た途端（に）】
意味：一...就...
接続：動詞た形
語感：瞬间发生且多为意外。
例文：部屋に入った途端、電話が鳴りました。 / 教室に着いた途端、忘れ物に気づいた。

【〜うえで】
意味：...之后；在...基础上
接続：動詞た形、名詞＋の
例文：両親と話し合った上で決めます。 / 調査した上で、レポートを書き始めた。

【〜次第】
意味：1. 一...就... 2. 取决于...
接続：動詞ます形（去掉ます） / 名詞
語感：1. 完成后马上做，多用于将来。
例文：スケジュールが決まり次第、すぐ連絡いたします。 / 手紙が届き次第、すぐに来てください。 / 天気次第だ。 / できるかどうかは君の努力次第だ。

【〜て以来】
意味：自...以来
接続：動詞て形
語感：以此为起点，状态一直持续。
例文：別れて以来、五年も経ってしまった。 / 入学して以来、一度も休んだことはない。

【〜てはじめて】
意味：...以后，才...
接続：動詞て形
語感：经历前项才意识到后项。
例文：別れてはじめて、君のありがたみがわかった。 / 病気になってはじめて、健康の大切さを知った。

【〜にあたって / 〜にあたり】
意味：值此...之际
接続：動詞辞書形、名詞
語感：用于特殊、重要的场合，书面语。
例文：新年を迎えるにあたり、心からのお祝いを申し上げます。 / 卒業にあたって、先生は私たちにいろいろ話してくれた。

【〜際に】
意味：...的时候
接続：動詞辞書形・た形、名詞＋の
語感：比「とき」更正式。
例文：ご使用の際に、説明書をよく読んでください。

【〜に際して】
意味：当...之际
接続：動詞辞書形、名詞
語感：非常正式的场合。
例文：卒業に際して、先生方に心からお礼を申し上げます。

【〜をきっかけに / 〜を契機として / 〜を機に】
意味：以...为契机，借...机会
接続：名詞
例文：あの事件をきっかけに戦争が始まった。

【〜おかげで】
意味：多亏...
接続：連体形、名詞＋の
語感：用于积极原因。
例文：あの人のおかげで、私たちは幸せに暮らせるのだ。 / 毎日練習したおかげで、上手になりました。

【〜せいで】
意味：都怪...
接続：連体形、名詞＋の
語感：用于消极原因。
例文：あなたのせいで、私は先生に叱られました。 / 雨のせいで、試合は中止になった。

【〜せいか】
意味：也许是因为...
接続：連体形、名詞＋の
語感：不确定的原因。
例文：熱のせいか、頭がフラフラしている。 / 暑さのせいか、ぜんぜん食欲がない。

【〜ために】
意味：由于...，因为...
接続：連体形、名詞＋の
語感：客观原因。
例文：病気のために、学校を休んだ。 / 無理をして授業に出席したために、風邪がもっと悪くなってしまった。

【〜だけに】
意味：正因为...，所以...
接続：連体形、名詞
語感：结果与原因相称。
例文：重大な事柄だけに、もう一度検討する必要がある。 / 頑張っただけに、今回の満点はさぞうれしいでしょう。

【〜だけあって / 〜だけのことはある】
意味：不愧是...，果然值得...
接続：連体形、名詞
語感：用于积极评价。
例文：さすがに彼だけあって、テレビも修理できる。 / 故宮は世界でも有名なだけあって、行ってみるだけのことはある。

【〜ばかりに】
意味：都是因为...，才导致...
接続：連体形
語感：用于意外的消极结果。
例文：油断したばかりに、事故を起こしてしまった。 / 学歴がないばかりに、大手企業に入れないのだ。

【〜ことから】
意味：因为...，由此...
接続：普通形
語感：作为判断、命名等的依据。
例文：二人の顔が似ていることから、親子ではないかと思った。 / この通りは政府機関が多いことから、官庁街と呼ばれている。

【〜ところから】
意味：因为...，从...来看
接続：普通形
語感：作为判断、命名等的依据。
例文：彼は何でも知っているところから、「生き字引」というあだ名で呼ばれている。

【〜ことだから】
意味：既然是...
接続：名詞＋の
語感：根据某人/某物的典型特征进行推测。
例文：真面目な田中さんのことだから、きっと試験に合格しますよ。 / 彼のことだから、どうせ時間通りに来ないだろう。

【〜もの / 〜もん】
意味：因为...嘛
接続：普通形＋もの
語感：主观强调原因，多用于关系亲近者之间。
例文：だって、先生がそうおっしゃったんだもの。 / だって、重いんだもん。

【〜ものだから】
意味：因为...
接続：連体形
語感：主观解释原因或辩解。
例文：この小説の主人公が好きなものですから、もう何度も読みました。 / 夕べ遅くまで仕事をしていたものですから、眠いんです。

【〜につき】
意味：因为...
接続：名詞
語感：用于书面通知、公告等。
例文：工事中につき、立ち入り禁止。 / 大雨につき、本日の試合は中止といたします。

【〜以上は】
意味：既然...，就...
接続：普通形
例文：お金がない以上、あきらめるしかない。 / 約束した以上は、守らなければならない。

【〜うえは】
意味：既然...，就...
接続：動詞辞書形・た形
語感：语气比「以上は」更强，更书面。
例文：引き受けた上は、全力を尽くさなければいけない。

【〜からには】
意味：既然...，就...
接続：普通形
語感：强调决心、义务。
例文：試合に出るからには、勝ちたい。

【〜あまり】
意味：由于过于...
接続：動詞辞書形、名詞＋の
語感：前接表示情感、感觉的词，导致不好的结果。
例文：心配のあまり、眠れなかった。 / 働きすぎたあまり、とうとう倒れてしまった。

【〜あまりの〜に / 〜あまりの〜で】
意味：由于过于...
接続：あまりの＋名詞＋に/で
例文：あまりの悲しさに、病気になってしまった。 / あまりの人出で、あきらめた。

【〜あげく】
意味：...的结果
接続：動詞た形、名詞＋の
語感：多指耗费时间精力后的消极结果。
例文：散々迷ったあげく、結局Ｂ大学にした。 / 考えに考えたあげく、会社を辞めることにした。

【〜末に】
意味：...的结果
接続：動詞た形、名詞＋の
語感：可好可坏。
例文：相談の末、一緒にやることにした。 / いろいろ考えた末、行くことにした。

【〜といっても】
意味：虽说...，但...
接続：普通形
例文：安いといっても、１０万円はかかるでしょう。 / 成績がよくなったといっても、読解の成績だけだ。

【〜からといって】
意味：虽说...，但并（不）...
接続：普通形
語感：后多接否定。
例文：先生だからといって、何でも知っているとは限らない。 / お酒を飲まないからといって、嫌いだというわけではない。

【〜ながら】
意味：虽然...但是...
接続：動詞ます形（-ます）、形容詞、名詞
例文：やると言いながら、結局何もしない。 / あの人は小さいながら、なかなか力がある。

【〜つつ（も）】
意味：虽然...但是...
接続：動詞ます形（-ます）
語感：比「ながら」更书面。
例文：そう言いつつも、彼女は決して行かないのだ。 / タバコをやめようと思いつつ、いまだにやめられない。

【〜ものの】
意味：虽然...但是...
接続：連体形
語感：结果与预想不符。
例文：大学は出たものの、就職先が見つからない。 / 日本に来たものの、日本語が分からなくて困っている。

【〜にもかかわらず】
意味：尽管...，却...
接続：普通形（な形容/名詞＋である/なの）、名詞
例文：周りは静かなのにもかかわらず、全然眠れなかった。 / 大雨にもかかわらず、試合は続行された。

【〜たところが】
意味：...（本以为），结果却...
接続：動詞た形
語感：表示意外。
例文：プロポーズに行ったところが、彼女は留守だった。 / 財布を開けたところが、お金は一銭も入っていなかった。

【〜たところで】
意味：即使...也（不）...
接続：動詞た形
語感：多为消极推测。
例文：今さら謝ったところで、許してくれないだろう。 / いくら待ったところで、彼は来ないでしょう。

【〜くせに】
意味：明明...却...
接続：連体形
語感：带有责备、抱怨的语气。
例文：自分で何もやらないくせに、人のやり方に文句ばかり言う。 / 知っているくせに、知らないふりをする。

【〜わりに（は）】
意味：与...相比，算是...
接続：連体形、名詞＋の
語感：前后项标准不匹配。
例文：日本は国土が狭いわりには、人口が多い。 / たくさん食べたわりには、太らない。

【〜にしては】
意味：作为...而言，算是...
接続：普通形、名詞
語感：与前项标准不太匹配。
例文：彼は日本に来てまだ半年にしては、日本語が非常にうまい。 / 博士にしては、あまり物を知らない人だ。

【〜反面・半面】
意味：一方面...，另一方面...
接続：連体形、名詞＋である
語感：同一事物的两个侧面。
例文：輸送に便利な反面、時間がかかる。 / あの先生は学生に厳しい反面、やさしいところもある。

【〜たとえ〜ても・でも】
意味：即使...，就算...
接続：動詞て形、い形容詞くて、な形容詞で、名詞で
例文：たとえ負けても、気を落としてはいけない。 / たとえ高くても、買わなければならない。

【〜としても】
意味：1. 即使...，就算... 2. 作为...也...
接続：普通形 / 名詞
語感：1. 假设。 2. 立场、身份。
例文：大地震が起こったとしても、このビルは大丈夫でしょう。 / 田中先生は詩人としても有名だ。 / 校長としても規則を守るべきだ。

【〜にしても】
意味：即使...；无论是...还是...；作为...也
接続：普通形、名詞
例文：だれがやるにしても、同じでしょう。 / 忙しいにしても、電話ぐらいくれてもいいのに。

【〜にしろ・〜にせよ】
意味：即使...；无论是...还是...
接続：普通形、名詞
語感：比「にしても」更书面。
例文：冗談にせよ、そんな話をすべきではない。 / どんなに辛いにしろ、最後まで頑張らなければならない。

【〜としたら・〜とすれば・〜とすると】
意味：如果...，假设...
接続：普通形
例文：Ｘが３だとすれば、Ｙは５になる。 / その話が本当だとしたら、大変なことだ。

【〜にしたら・〜にすれば】
意味：在...看来
接続：名詞
語感：站在某人立场。
例文：いくら大きくなっても、親にしたらまだ子供なのだ。 / 生活が苦しくても、彼と一緒にいられることは、彼女にしたら最大の幸福だ。

【〜（よ）うものなら】
意味：一旦...的话
接続：動詞意向形＋ものなら
語感：就会发生不好的事。
例文：ちょっとでもミスしようものなら、命が危ない。 / 本当のことを話そうものなら、大変なことになる。

【〜てからでないと】
意味：如果不先...，就不能...
接続：動詞て形＋からでないと
例文：みんなと相談してからでないと、一人では決められない。 / 親になってからでないと、親としての苦労は分からない。

【〜ないことには】
意味：如果不...，就（不）...
接続：動詞ない形＋ことには
例文：やってみないことには、その面白さがわからないでしょう。 / Ｎ２に合格しないことには、この大学には入れない。

【〜なしには・〜なくしては】
意味：没有...（就不能）...
接続：名詞＋なしには
例文：愛なしには、何の人生か。 / 政府からの許可なくしては、この計画は実施できないだろう。

【〜さえ〜ば】
意味：只要...就...
接続：名詞＋さえ＋動詞ば形、動詞ます形（-ます）＋さえすれば
例文：あなたさえいれば、何もいらない。 / お金さえあれば、何でも買える。 / この問題を解決しさえすれば、あとは簡単だ。

【〜限り】
意味：只要...
接続：動詞辞書形・ない形
語感：在...期间/范围内。
例文：用事がない限り、必ず参加します。 / 命がある限り、彼と一緒にいたい。

【〜限りでは】
意味：据...所知/看/听
接続：動詞辞書形・た形
語感：多为认知类动词，如「知る」「見る」「聞く」。
例文：私の知る限りでは、彼は悪い人ではありません。 / 私が調べた限りでは、彼は無実だ。

【〜に限って】
意味：偏偏...；只有...
接続：名詞
語感：表示某种情况是特别的。
例文：買いたい時に限って、売り切れだ。 / うちの子に限って、そんなことをするはずがない。

【〜に限り】
意味：只限于...
接続：名詞
語感：特别许可或规则。
例文：今回に限り、許してやる。 / 本日ご来店のお客様に限り、全品１割引です。

【〜に限る】
意味：1. 限于... 2. ...是最好的
接続：名詞 / 動詞辞書形・ない形、名詞
語感：2表示说话者的主观判断。
例文：今度のイベントは女性に限る。 / 発表者は３０人もいるから、一人１５分に限ります。 / 疲れた時は寝るに限る。 / 夏は冷たいビールに限る。

【〜に限らず】
意味：不仅...而且...
接続：名詞
例文：学部生に限らず、院生の就職も難しくなった。 / この施設は選手たちに限らず、一般の人も使える。

【〜とは限らない】
意味：未必...，不一定...
接続：普通形
例文：高いものが必ずしもいいものとは限らない。 / 中国人だからといって、中国文化を全部知っているとは限らない。

【〜にとどまらない】
意味：不仅限于...，不止于...
接続：名詞、動詞辞書形＋だけ
語感：范围更广。
例文：言いたいことはこれだけにとどまらない。 / コロナウイルスは都市にとどまらず、農村にも広がっている。

【〜のみならず】
意味：不仅...而且...
接続：普通形、名詞
語感：书面语。
例文：この漫画は子供のみならず、大人にも読まれている。 / 父のみならず、母までも反対している。

【〜ばかりでなく】
意味：不仅...而且...
接続：連体形、名詞
例文：あの人は英語ばかりでなく、日本語も話せる。

【〜ばかりか】
意味：不但...，甚至...
接続：連体形、名詞
語感：后项程度更深。
例文：私ばかりか、先生でさえ知らないだろう。 / 自分を反省しないばかりか、責任を他人に押しつける。

【〜どころか】
意味：不但不...反而...；哪里谈得上...
接続：連体形、名詞
例文：成績はよくなるどころか、どんどん悪くなった。 / 外国語どころか、母国語の文章さえ書けない大学生がいる。

【〜どころではない】
意味：不是...的时候
接続：動詞辞書形、名詞
語感：没时间/精力/心情做某事。
例文：宿題が多いので、テレビを見るどころではない。 / 忙しくて、映画を見るどころではない。

【〜上に】
意味：而且...，再加上...
接続：連体形、名詞＋の
例文：あの店は料理がまずい上に、値段も高い。 / あそこの果物は新鮮な上に、値段も安い。

【〜さえ・でさえ】
意味：甚至...，就连...
接続：名詞
例文：これは子供でさえわかることだ。 / 日本人の苗字は難しいので、日本人でさえ困ることがあります。

【〜ことか】
意味：多么...啊！
接続：連体形
語感：前接「どんなに」「どれほど」「なんと」等，表示感叹。
例文：どんなに便利なことか。 / 昨日あなたに会えてどれほど嬉しかったことか。

【〜はもちろん・〜はもとより】
意味：...自不必说
接続：名詞
例文：彼は英語はもちろん、日本語も話せる。 / このことには、父はもちろん、母までも反対する。

【〜はしない・〜もしない】
意味：绝不...
接続：動詞ます形（-ます）＋はしない
語感：加强否定语气。
例文：決して約束を忘れはしないから、心配しないでください。 / うそなんかつきはしませんよ。

【〜っこない】
意味：绝不可能...
接続：動詞ます形（-ます）＋っこない
例文：女の心なんて、わかりっこないよ。 / こんな難しい問題は、解けっこない。

【〜からして】
意味：从...来看，单就...而言
接続：名詞
例文：表情からして、彼は失恋したようだ。 / 外見からして、金持ちそうだ。

【〜こそ】
意味：正是...，才是...
接続：名詞、動詞て形
語感：强调。
例文：努力してこそ、成功できるのだ。 / これこそ私が探しているものだ。

【〜やら〜やら】
意味：...啦...啦
接続：名詞、動詞辞書形、い形容詞
語感：列举，暗示杂乱或忙不过来。
例文：家に帰ると、料理やら洗濯やらで大変だ。 / 帰国前、買い物やら荷造りやらで、たいへん忙しかった。

【〜も〜ば〜も】
意味：既...又...
接続：名詞＋も＋動詞ば形＋ば、名詞＋も
例文：あの人は給料も高ければ能力もある。 / 彼は酒も飲めば、タバコも吸う。

【〜につけ〜につけ】
意味：无论是...还是...
接続：名詞、動詞辞書形、い形容詞
語感：在...的时候，总会...
例文：いいにつけ悪いにつけ、結果は先生に伝えるべきだ。 / 嬉しいにつけ悲しいにつけ、彼と話したい。

【〜にしても〜にしても】
意味：无论是...还是...
接続：名詞、動詞辞書形
例文：高いにしても安いにしても、買うつもりだ。 / 進学するにしても就職するにしても、自分で決めなければならない。

【〜というと】
意味：谈起...，说到...
接続：名詞
例文：川端康成というと、「雪国」という小説が心に浮かぶ人が多いでしょう。 / 映画というと、「ハリウッド」を思い出す。

【〜といえば】
意味：1. 说起... 2. 要说...的确是...，但是...
接続：名詞 / 普通形
語感：1. 引出联想。 2. 承认某种情况但有保留。
例文：日本といえば、すぐ富士山を思い出します。 / 田中さんといえば、最近仕事を辞めたそうですよ。 / 不便といえば不便だが、何とかなるよ。 / 高いといえば高いですが、必需品ですから、買っておいたほうがいいですよ。

【〜といったら】
意味：提起...，说到...
接続：名詞
語感：后接带有惊讶、感叹的评价。
例文：その話を聞いたときの彼女の顔といったら、本当に悲しそうだった。 / 紅葉といったら高尾山だ。あの景色の美しさといったら、言葉で言い表せないほどだ。

【〜かというと・〜かといえば】
意味：要说为什么...，那是因为...
接続：普通形
例文：なぜ成績が悪いかというと、普段の勉強が足りないからです。 / 大学を卒業したらどうするかといえば、まだ何も決めていない。

【〜からいうと・〜からいえば・〜からいって】
意味：从...来讲
接続：名詞
語感：以...为依据进行判断。
例文：彼は実力からいうと、大学に入るのは大丈夫だ。 / 彼女は妹だが、性格からいうと、私と全然違っている。

【〜からすると・〜からすれば】
意味：从...来看
接続：名詞
語感：根据某个角度推测。
例文：話し方からすると、彼は東京の人ではないようだ。 / 収入からすると、そんな高いかばんはとても買えない。

【〜から見ると・〜から見れば・〜から見て】
意味：从...看来
接続：名詞
語感：角度、立场。
例文：親の立場から見ると、子供はいくつになっても子供です。 / 服装から見れば、彼は金持ちのようだ。

【〜にしてみれば】
意味：在...看来
接続：名詞（人）
語感：站在某人立场。
例文：初心者にしてみれば、もっとわかりやすく話してもらいたいだろう。 / 私にしてみれば、どうでもいいことだ。

【〜はともかく】
意味：...暂且不论，...姑且不说
接続：名詞
例文：この店はサービスはともかく、味は悪くない。 / 他人のことはともかく、まず自分がどうするかを決めるべきだ。

【〜ならともかく】
意味：如果...的话另当别论，但是...
接続：名詞
例文：勉強しているならともかく、遊んでばかりいては成績がよくなるはずがない。 / 一度の遅刻ならともかく、何度も遅刻するのはだめだ。

【〜ざるを得ない】
意味：不得不...
接続：動詞ない形（する→せざるを得ない）
語感：违反本意。
例文：今回の失敗はこちらにも責任があると言わざるを得ない。 / 事故を起こしたのだから、仕事を辞めざるを得ない。

【〜かねる】
意味：难以...，不便...
接続：動詞ます形（-ます）
語感：委婉拒绝。
例文：私一人では決めかねます。 / せっかく作ってくれた料理なので、まずいとは言いかねる。

【〜かねない】
意味：有可能...，说不定会...
接続：動詞ます形（-ます）
語感：用于消极推测。
例文：あの人は金のためにはそんなことをやりかねない。 / 早く行かないと、７時の列車に遅れかねない。

【〜恐れがある】
意味：恐怕会...
接続：動詞辞書形、名詞＋の
語感：有不好的可能性。
例文：このまま森林を伐採し続ければ、ここは砂漠になる恐れがある。 / 台風は５日に沖縄地方に上陸する恐れがある。

【〜ようがない】
意味：无法...，想...也做不到
接続：動詞ます形（-ます）
例文：これ以上悩んでもどうしようもない。あきらめよう。 / その時の寂しさは言いようがない。

【〜にも〜ない】
意味：想...也...不了
接続：動詞意向形＋にも＋動詞可能形（否定）
例文：心配事があるので、寝ようにも寝られない。 / お金がなくて、留学しようにもできない。

【〜（より）ほか（は）ない】
意味：只好...，只能...
接続：動詞辞書形
語感：没有别的办法。
例文：Ｎ２試験に合格するためには、今から真面目に勉強するよりほかはない。 / いくら焦ってもどうしようもない。このまま待つほかない。

【〜において】
意味：在...，于...
接続：名詞
語感：相当于「で」。
例文：卒業式は学生センターにおいて行われます。 / ２０２０年オリンピック大会は東京において開催されました。

【〜における】
意味：在...中的...
接続：名詞
語感：相当于「での」，作定语。
例文：学校における教育は、子どもにとっていかに大切であるか。 / 各分野における発展を期待している。

【〜に関して】
意味：关于...
接続：名詞
例文：両国は国際問題に関して意見を交換した。 / 教育改革に関して論文を発表した。

【〜について】
意味：关于...
接続：名詞
例文：この問題について詳しく説明していただきたいです。 / 田中先生は日本の文化についていろいろ話してくれました。

【〜に対して・〜に対する】
意味：对于...；与...相反
接続：名詞
例文：お客様に対してこのような言葉遣いをしてはいけない。 / 父が厳しいのに対して、母は優しい。 / 学校は教師に対する要求が厳しい。

【〜に比べて】
意味：与...相比
接続：名詞
例文：今年の夏は去年に比べて、少し涼しいようです。

【〜にとって】
意味：对...来说
接続：名詞
語感：从...立场来看。
例文：これは子供にとって貴重な経験だ。 / 私にとっての第一印象は、町の狭いことでした。

【〜によって】
意味：因...而异；根据...；由...；由于...
接続：名詞
例文：先生によって、教え方が違います。 / 成績によって、クラスを分けます。 / この小説は魯迅によって書かれたものだ。 / 地方によって、風俗習慣が違う。

【〜によっては】
意味：根据...情况，有时也...
接続：名詞
例文：場合によっては、スケジュールが変更になるかもしれない。 / 人によっては、だまされるかもしれない。

【〜に基づいて】
意味：根据...，以...为基础
接続：名詞
語感：以事实、数据为基准。
例文：今までの経験に基づいて判断する。 / これは実話に基づいて書かれた小説だ。

【〜をもとに（して）】
意味：根据...，以...为原型
接続：名詞
語感：以素材、原材料为基础。
例文：これまでのデータを基にして研究を行う。 / このテレビドラマは伝説を基にして作られた。

【〜のもとで・〜のもとに】
意味：在...之下
接続：名詞
語感：在影响、条件下。
例文：先生の指導のもとで、研究を行う。

【〜上で】
意味：在...方面；在...之后
接続：名詞＋の、動詞た形
例文：ビザの申請をする上で注意しなければならないことがある。 / いろいろ考えた上で、会社を辞めることにした。 / 父と相談した上で、ご返事をします。

【〜上】
意味：...上
接続：名詞
語感：抽象方面。
例文：これは法律上の問題です。

【〜をめぐって・〜をめぐる】
意味：围绕...
接続：名詞
語感：争论、讨论的话题。
例文：教育問題をめぐって、話し合います。 / 環境問題をめぐる対策を検討する。

【〜にわたって】
意味：长达...；遍及...
接続：名詞
語感：在整个时间、空间、范围。
例文：手術は１４時間にわたって行われた。 / この研究には多分野にわたる広い知識が必要である。 / 彼は３時間にわたって演説を続けた。

【〜を通じて・〜を通して】
意味：通过...；在整个...期间
接続：名詞
語感：表示媒介或整个期间。
例文：テレビを通じて広告をする。 / 南極は一年を通して寒さが厳しい。 / これは彼の一生を通して、最も苦しい時期だった。

【〜から〜にかけて】
意味：从...到...
接続：名詞
語感：大致的时间或空间范围。
例文：東京は５月から８月にかけてよく雨が降る。 / 九州から四国にかけて、大雨が降っている。

【〜かわりに】
意味：1. 代替... 2. ...的另一方面；作为...的交换/代价
接続：名詞＋の / 連体形
例文：ＢさんはＡさんの代わりに主役を演じる。 / 部長の代わりに、会議に出席した。 / 日本語を教えてもらう代わりに、中国語を教えてあげよう。 / このマンションは駅に近いかわりに、家賃が高い。 / 今日は映画を見に行くかわりに、家で小説でも読もう。

【〜にかわって】
意味：代替...
接続：名詞
例文：母にかわって、お礼のあいさつをいたします。 / 部長にかわって、私があいさつをいたします。

【〜をはじめ（として）】
意味：以...为代表
接続：名詞
語感：列举最重要的。
例文：この映画は北京をはじめ、全国の大都市で上映される。 / 中国をはじめとするアジアの国々がこの会議に出席した。

【〜とおり】
意味：按照...，如同...
接続：名詞＋の・どおり、動詞辞書形・た形
例文：成績表は次のとおりです。 / 先生の教えどおりにする。 / 先生が教えたとおりにやる。 / ご覧のとおり、これが私の家です。

【〜に応じて】
意味：根据...，顺应...
接続：名詞
語感：与前项变化相适应。
例文：個人の希望に応じて、個別指導を行う。 / 収入に応じて生活する。 / お客様の注文に応じて作る。

【〜にこたえて】
意味：回应...
接続：名詞
語感：回应期待、要求等。
例文：みんなの期待にこたえて、彼は新記録を立てた。 / アンコールにこたえて、もう一曲演奏した。

【〜に反して】
意味：与...相反；违反...
接続：名詞
例文：予想に反して、出席者が多かった。 / 交通規則に反する行為をしてはいけない。

【〜に加えて】
意味：再加上...，加之...
接続：名詞
例文：大雪に加えて風まで吹いてきた。 / 過労に加えて病気になり、とうとう倒れてしまった。

【〜に沿って】
意味：沿着...
接続：名詞
語感：沿着道路、方针、计划等。
例文：政府の方針に沿って、都市建設の計画を実施する。 / カリキュラムに沿って授業を進める。

【〜に従って】
意味：随着...；按照...，根据...
接続：名詞、動詞辞書形
例文：経済の発展に従って、人々の生活がよくなった。 / 政府の方針に従って、建設の仕事に力を入れた。 / 山を登るにしたがって、だんだん寒くなってきた。

【〜につれて】
意味：随着...
接続：名詞、動詞辞書形
語感：自然而然的单向变化。
例文：時が経つにつれて、愛情が深まった。 / 物価の高騰につれて、生活も苦しくなった。

【〜に伴って】
意味：随着...，伴随...
接続：名詞、動詞辞書形
例文：経済発展に伴って、環境汚染もひどくなった。

【〜とともに】
意味：与...同时；和...一起
接続：名詞、動詞辞書形
例文：地震が起こると共に、火災もあちこちで発生した。 / みんなと共に頑張りましょう。 / 卒業と共に、直ちに結婚する。

【〜にかかわらず】
意味：无论...，不管...
接続：名詞、動詞辞書形＋か＋ない形＋か
例文：男女にかかわらず、誰でも申請できます。 / 経験のあるなしにかかわらず、誰でも参加できる。

【〜を問わず】
意味：无论...，不管...
接続：名詞
例文：国籍を問わず、誰でも参加することができる。 / 距離を問わず、バス代は２１０円です。

【〜抜きで】

接続：名詞
例文：冗談抜きで、真剣にこの問題を考えなさい。 / 晩ご飯抜きで、授業に来る学生が多い。

【〜抜きにして】
意味：去掉...，省去...
接続：名詞
例文：冗談は抜きにして、真面目に考えてください。 / 礼儀は抜きにして、思う存分飲もう。

【〜はずだ】
意味：应该...
接続：連体形、名詞＋の
語感：有把握的推测。
例文：会議は２時に始まるはずです。 / 妹は今年卒業するはずです。

【〜はずがない】
意味：不可能...，没道理...
接続：連体形、名詞＋の
例文：夏休み中だから、彼女が忙しいはずがない。

【〜わけだ】
意味：难怪...；当然...
接続：連体形
語感：自然而然的结论。
例文：１０年も日本にいたから、日本語が上手なわけだ。

【〜わけがない】
意味：不可能...，没道理...
接続：連体形
例文：あんなに優しい彼が、そんなことをするわけがない。

【〜わけではない・〜わけでもない】
意味：并不是...，并非...
接続：連体形
例文：お酒が嫌いなわけでもないが、医者に注意されたので飲まないことにしている。 / このクラスの学生がみんな真面目に勉強するわけではない。

【〜というわけではない】
意味：并不是说...
接続：普通形
例文：採用は能力次第で、必ずしも大卒というわけではない。 / 参加したくないというわけではないが、時間がないんです。

【〜わけにはいかない】
意味：不能...
接続：動詞辞書形
語感：因社会常理、人情等原因。
例文：風邪をひいたが、最近仕事が忙しいので、会社を休むわけにはいかない。 / 約束したので、行かないわけにはいかない。

【〜ものだ】
意味：1. 理应...，本来就... 2. 真...啊 3. 真想...啊 4. 过去常常...
接続：連体形 / 動詞たい形 / 動詞た形
語感：1. 道理、常识。 2. 强烈的感叹。 3. 强烈的愿望。 4. 怀念。
例文：良薬は口に苦いものだ。 / 人の家へ伺う時は、電話をしてから行くものだ。 / 時間の経つのは早いものだ。 / 人生とは、はかないものだ。 / 子供の頃から、大きくなったら宇宙旅行をしたいものだと思っていた。 / 早く国へ帰って家族に会いたいものだ。 / 祖母は昔よくこう言ったものだ。 / 昔はよくあの公園へ散歩に行ったものだ。

【〜ものではない】
意味：不该...，不应...
接続：連体形
語感：违反常识的告诫。
例文：人の悪口を言うものではない。 / 先生に対してそんなことを言うものではない。

【〜というものだ】
意味：这才真是...
接続：普通形
語感：表示强调性的断定。
例文：自分のことだけでなく、他人のことも考えられる人、それが大人というものだ。 / 成績のいい学生にだけチャンスを与えるのは、不公平というものだ。

【〜というものではない】
意味：并非...，并不等于...
接続：普通形
例文：言葉の勉強は、文法がわかればいいというものではない。 / お金があれば、何でも買えるというものではない。

【〜ものか】
意味：怎么可能...
接続：連体形
語感：表示强烈的否定。
例文：あんなまずい店に二度と行くものか。 / あんな人に恋人ができるものか。

【〜ものがある】
意味：确实...，真让人觉得...
接続：連体形
語感：表示某种感觉。
例文：昨日見た映画には、とても感動するものがあった。 / さすが大作家だけあって、どの作品も素晴らしいものがある。

【〜べきだ】
意味：应该...
接続：動詞辞書形
語感：说话人的主张、建议。
例文：やるべきことは、ちゃんとやろう。 / 学生はまず勉強すべきだ。 / 親に対して、こんな失礼なことを言うべきではない。

【〜ことだ】
意味：应该...，不该...
接続：動詞辞書形・ない形
語感：表示劝告、要求。
例文：合格したければ、よく勉強することだ。 / 上手になりたければ、しっかり練習することだ。

【〜ことに（は）】
意味：令人...的是...
接続：動詞た形、い/な形容詞＋な
例文：困ったことに、あの人の名前がどうしても思い出せなかった。 / 不思議なことに、会社を辞めたら、よく眠れるようになった。

【〜ことはない】
意味：不必...
接続：動詞辞書形
例文：何も心配することはありません。 / そのぐらいのことで、怒ることはないでしょう。

【〜ほど〜ない】
意味：不像...那么...
接続：名詞
例文：今年の夏は暑いが、去年ほどではない。 / この映画は、想像したほど面白くない。

【〜ほど〜はない】
意味：没有比...更...的了
接続：名詞
例文：健康ほど大切なものはない。 / 彼女ほどきれいな人はいない。

【〜とみえる】
意味：看来...，可见...
接続：普通形
例文：彼は赤い顔をしていて、相当怒っているとみえる。 / 雨が降ったとみえる。

【〜にすぎない】
意味：只不过是...
接続：普通形、名詞
語感：强调程度低。
例文：収入は月二万円にすぎない。 / ピアノは趣味として練習しているにすぎない。

【〜にほかならない】
意味：正是...，不外乎...
接続：名詞
例文：彼に成功をもたらしたものは、今までの努力にほかならない。

【〜でなくてなんだろう】
意味：不是...又是什么呢？
接続：名詞
語感：带有强烈感情的断定。
例文：これが愛でなくてなんだろう。 / これが命でなくてなんだろう。

【〜に相違ない】
意味：一定...，肯定...
接続：普通形、名詞
語感：书面语，基于根据的客观推断。
例文：私が見たのは、この人に相違ありません。

【〜に決まっている】
意味：一定...，肯定...
接続：普通形、名詞
語感：口语，主观确信。
例文：あの人の言うことは、うそに決まっている。

【〜に違いない】
意味：一定...，肯定...
接続：普通形、名詞
語感：主观推测。
例文：あの男は人の話に何でも「はいはい」と言っている。日本人に違いない。

【〜のではないだろうか】
意味：...吧？
接続：連体形
語感：委婉地提出看法或疑问。
例文：いったん失敗をしたら、また失敗をするのではないかと考えてしまう。 / 田中さんは昨日来たかな？ 来たのではないかと思うけど。

【〜てならない】
意味：...得不得了
接続：動詞て形、い/な形容詞
語感：自然产生的情感或感觉，无法抑制。
例文：お腹が痛くてならない。 / 両親に会いたくてならない。

【〜てたまらない】
意味：...得不得了
接続：動詞て形、い/な形容詞
語感：无法忍受的感觉或愿望。
例文：一人で日本に来て、今は寂しくてたまらない。 / 試合に勝って、うれしくてたまらない。

【〜てしかたがない・〜てしょうがない】
意味：...得不得了
接続：動詞て形、い/な形容詞
例文：北京の夏は暑くてしかたがない。 / 私の家は学校から遠くて、不便でしかたがない。

【〜てはいられない】
意味：不能再...下去了
接続：動詞て形
語感：因情况紧急或有别的事要做。
例文：子供の不行儀に対して、黙ってはいられない。 / もうすぐＮ２試験だから、のんびり遊んではいられない。

【〜てばかりいる】
意味：光是...，一个劲儿地...
接続：動詞て形
例文：あの人はいつも怒ってばかりいる。 / もうすぐＮ２試験だから、遊んでばかりはいられない。

【〜ばかりだ】
意味：光是...；不断地...；只剩下...
接続：動詞辞書形
語感：多为消极变化。
例文：彼女は何も言わず、泣くばかりだ。 / 状況は悪くなるばかりだ。 / 今はただ祈るばかりだ。

【〜ずにはいられない】
意味：不能不...，忍不住...
接続：動詞ない形＋ずにはいられない
語感：情感油然而生。
例文：この映画を見て、誰も感動せずにはいられないだろう。 / こんなひどいことをされて、怒らないではいられません。

【〜一方だ】
意味：一个劲儿地...，越来越...
接続：動詞辞書形
語感：多为消极变化。
例文：最近、物価は上がる一方だ。 / どういうわけか、最近私は太る一方だ。

【〜つもりだ】
意味：自以为...；就当作...
接続：連体形、名詞＋の
例文：本人は面白いことを言っているつもりだろうが、他の人にはその冗談は通じなかった。 / 旅行したつもりで、お金を銀行に預けた。 / 先生になったつもりで、この教科書をもう一度読み直しなさい。

【〜（よ）うとする】
意味：正打算...，将要做...
接続：動詞意向形
例文：彼女の笑顔は忘れようとしても忘れられない。 / 出かけようとしたところに、電話がかかって来た。

【〜ながら】
意味：一边...一边...；保持...原样
接続：動詞ます形（-ます）、名詞
例文：お茶を飲みながら話しましょう。 / 皮ながら食べる。 / テレビを見ながら食事をしてはいけない。

【〜つつ】
意味：一边...一边...
接続：動詞ます形（-ます）
語感：比「ながら」更书面。
例文：酒を飲みつつ、月見をする。 / アルバイトをしつつ、大学に通っている。

【〜つつある】
意味：正在...
接続：動詞ます形（-ます）
語感：表示宏观、持续的变化过程。
例文：あの都市の様子は変わりつつある。 / 自然が破壊されつつある。

【〜ば〜ほど】
意味：越...越...
接続：動詞ば形＋動詞辞書形＋ほど
例文：煮れば煮るほど、柔らかくなる。 / 外国語は練習すればするほど、うまくなる。

【〜中を】
意味：在...之中
接続：連体形、名詞＋の
語感：多用于恶劣环境或繁忙之时。
例文：お忙しい中を、よくいらっしゃいました。 / 雨の中を帰ってきた。

【〜きり】
意味：...之后就再也（没）...
接続：動詞た形
例文：彼はアメリカへ行ったきり、帰ってこない。 / 三年前、彼に一度会ったきりだ。 / 去年東京に行ったきり、まだ電話もしてくれない。

【〜かのようだ】
意味：仿佛...似的
接続：普通形＋かのようだ
例文：深刻な顔をして、まるで世界の終わりが来るかのようだ。 / 自分の子供が帰ってきたかのように、母は友達を親切にもてなしてくれた。

【〜ふりをする】
意味：装作...
接続：連体形
例文：寝たふりをしないで、早く起きなさい。 / 彼は忙しそうなふりをしている。

【〜ところだった】
意味：险些...，差点儿...
接続：動詞辞書形
例文：もう少しで走ってきたトラックとぶつかるところだった。 / もうちょっとでけがをするところだった。

【〜ことになっている・〜こととなっている】
意味：（按规定/计划）...
接続：連体形
例文：両国の首脳会議は来月四日に開かれることになっている。 / 鈴木さんとの約束では、９時までに東京駅に行くことになっている。

【〜ようになっている】
意味：（机械、系统等）构造成...；（事物）变成...
接続：動詞辞書形・ない形
例文：このドアは閉めると、ひとりでに鍵がかかるようになっている。 / 何か故障があった場合、その機械はひとりでに電源が切れるようになっている。

【〜得る】
意味：能...，可能...
接続：動詞ます形（-ます）
例文：そんなことは、あり得ないよ。 / この問題を解き得た人は一人もいない。

【〜かけ・〜かける】
意味：刚开始...，...了一半
接続：動詞ます形（-ます）
語感：没做完。
例文：机には食べかけのパンが残されている。 / 読みかけた本を返した。

【〜がち】
意味：容易...，常常会...
接続：動詞ます形（-ます）、名詞
語感：多为消极倾向。
例文：これはありがちな間違いだ。 / 彼女は小さいころ病気がちで、あまり外で遊ばなかった。

【〜がる】
意味：（第三人称）感觉...，想要...
接続：形容詞語幹、動詞たい形
例文：弟は新しいものを見ると、すぐ欲しがる。 / 人の嫌がることは、なるべくやめたほうがいい。

【〜気味】
意味：有点...的样子，稍微...
接続：動詞ます形（-ます）、名詞
例文：今日は少し風邪気味で、頭が痛い。 / 初めての演説なので、彼女は少し緊張気味だった。

【〜きる】
意味：...完；完全...
接続：動詞ます形（-ます）
例文：この本は一週間では読み切れない。 / 辞書に頼りながら、やっとこの小説を読み切った。

【〜げ】
意味：...的样子
接続：い/な形容詞語幹
例文：家の外で子猫が悲しげに鳴いている。 / このぐらいのことで怒るのは、大人げない。

【〜だらけ】
意味：满是...
接続：名詞
語感：多为令人不快的东西。
例文：彼は借金だらけで、何度も自殺を図った。 / この文章は間違いだらけで、直しようがない。

【〜っぽい】
意味：有...的倾向；像...似的
接続：動詞ます形（-ます）、名詞、い形容詞
例文：彼女はもう大学を卒業したが、子供っぽいところがまだある。 / 田中さんは忘れっぽくなりました。

【〜抜く】
意味：（通过努力）...到底，完成
接続：動詞ます形（-ます）
例文：ついに２０００メートルを走りぬいた。 / 決めた以上、最後までやり抜くべきだ。

【〜向き】
意味：适合...
接続：名詞
語感：性质上适合。
例文：子供向きの料理もあれば、大人向きの料理もある。 / あの酒は女性向きで、あまり強くない。

【〜向け】
意味：面向...，为...而设计的
接続：名詞
語感：以...为对象。
例文：輸出向けの製品は、皆厳しい品質検査を受けている。 / これは日本語学習者向けに作られた教材で、すごく面白い。

【〜ずつ】
意味：每...
接続：数量詞
例文：五人ずつでグループを作る。 / 一人に３枚ずつ配る。

【〜おきに】
意味：每隔...
接続：数量詞
例文：１メートルおきに木を一本植える。 / ３時間おきに薬を飲んでください。

【〜ごとに】
意味：每...
接続：名詞、動詞辞書形
語感：强调频率。
例文：このバスは五分ごとに出る。 / 日曜日ごとにプールに行く。 / 五人ごとにグループを作る。

【〜なんて】
意味：「など」的口语，表示列举、轻蔑或意外
接続：普通形、名詞
例文：こんなところで君に会うなんて、びっくりしたよ。

【〜なんか】
意味：「など」的口语，表示列举或轻视
接続：普通形、名詞
例文：小説を読んだりなんかして、暇をつぶす。

【〜っけ】
意味：...来着
接続：動詞た形、形容詞た形、名詞だった
語感：回忆、确认记不清的事。
例文：昨日の朝ごはん、何食べたっけ？ / 三年前はどこで働いていたんだっけ？

【〜（よ）うではないか】
意味：...吧！
接続：動詞意向形
語感：号召、劝诱。
例文：最後まで頑張ってみようではないか。

【〜や否や / 〜や】
意味：刚一……就……
接続：動詞辞書形
語感：两个动作几乎同时发生，没有时间间隔。后项多为意料之外的、瞬间发生的事情。
例文：授業終了のチャイムが鳴るや否や、生徒たちは教室を飛び出していった。

【〜が早いか】
意味：一……就……
接続：動詞辞書形
語感：极其强调速度之快。后项多为意料之外的、瞬间的动作或变化。前后主语通常是同一个。
例文：彼はドアを開けるが早いか、カバンを放り投げてベッドに倒れ込んだ。

【〜なり】
意味：一……就……
接続：動詞辞書形
語感：前后主语必须是同一个人，后项是出乎意料的、异常的动作。
例文：部長は部屋に入ってくるなり、大声で怒鳴り始めた。

【〜そばから】
意味：随……随……，刚……就……
接続：動詞辞書形・た形
語感：特指一个动作反复进行，但后项总是马上发生，让前项的努力白费，带有无奈感。
例文：新しい単語を覚えるそばから、忘れてしまう。

【〜がてら】
意味：顺便……
接続：動詞ます形、名詞
語感：在做主要动作A的同时，利用这个机会也做了B。
例文：散歩がてら、コンビニで牛乳を買ってきた。

【〜かたがた】
意味：顺便……，兼……
接続：名詞
語感：比がてら更正式。一个动作兼具两个目的。
例文：部長のお見舞いかたがた、仕事の状況を報告してきた。

【〜かたわら】
意味：一边（主业）……一边（副业）……
接続：動詞辞書形、名詞＋の
語感：在做主要工作的同时，长期地从事另一项活动。
例文：彼は大学で教えるかたわら、翻訳の仕事もしている。

【〜てからというもの】
意味：自从……以后，就一直……
接続：動詞て形
語感：以前项为契机，后项发生了很大的变化，并且该状态一直持续。
例文：子供が生まれてからというもの、夫婦の会話は子供のことばかりだ。

【〜を限りに】
意味：以……为界，……之后不再
接続：名詞（表示时间、次数）
語感：表示某个持续至今的行为或状态的终结。
例文：今日を限りに、タバコをやめるぞ！

【〜を皮切りに】
意味：以~为开端/第一炮
接続：名詞
語感：之后接连不断地发生同类事情。
例文：この映画は、カンヌ映画祭での受賞を皮切りに、世界中で大ヒットした。

【〜とあって】
意味：因为，由于……特殊情况
接続：普通形、名詞
語感：因为是理所当然的特殊情况，所以产生某种结果是正常的。
例文：有名人が来るとあって、会場には多くのファンが詰めかけた。

【〜こととて】
意味：因为……
接続：連体形
語感：书面语，较为陈旧。表示一种辩解、请求原谅的语气。
例文：何も知らぬこととて、大変失礼いたしました。

【〜ことだし】
意味：况且……，再说……
接続：連体形
語感：在多个理由中，举出一个作为代表。常用于提出建议或决定。
例文：天気もいいことだし、どこかに出かけない？

【〜こともあって】
意味：也是因为……的原因
接続：連体形
語感：表示原因之一，暗示还有其他原因。
例文：疲れていたこともあって、昨日は早く寝てしまった。

【〜ゆえに】
意味：因为……所以……
接続：連体形、名詞＋の
語感：非常正式的书面语，阐述深刻的道理或逻辑因果。
例文：悪天候故、フライトは欠航となった。

【〜からこそ / 〜ばこそ】
意味：正因为……才……
接続：普通形 / 動詞ば形
語感：强调理由的唯一性和强烈性。
例文：あなたのことを心配しているからこそ、厳しく注意するんだ。

【〜ではあるまいし】
意味：又不是……
接続：名詞
語感：用于批评或劝告对方，表示“你又不是A，所以不该做B”。
例文：赤ちゃんではあるまいし、自分のことは自分でやりなさい。

【〜始末だ】
意味：（最终）落得……的地步
接続：連体形
語感：表示事情发展到最终的、糟糕的结果。
例文：彼はギャンブルに手を出し、ついには会社のお金にまで手をつける始末だ。

【〜た手前】
意味：既然已经...，就不得不...
接続：動詞た形、名詞＋の
語感：表示因为自己已经做了某件事，所以从维护立场、面子出发，后续不得不采取某种行动。带有“骑虎难下”的语感。
例文：みんなに「手伝う」と約束した手前、今さら「できない」とは言えない。

【〜はずみに】
意味：……的瞬间/冲力下，（意外地）……
接続：動詞た形
語感：在前一个动作的势头下，发生了意料之外的后项。
例文：くしゃみをしたはずみに、腰を痛めてしまった。

【〜ずじまい】
意味：终究还是没能……
接続：動詞ない形（去掉ない）
語感：想做某事但最终因故没能实现，表示遗憾。
例文：ずっと行きたかった旅行に、結局行けずじまいだった。

【〜には〜が】
意味：……倒是……，不过……
接続：動詞辞書形＋には＋動詞辞書形＋が
語感：先点头承认，再摇头转折。真正的重点和想表达的不满、问题或困难，都放在が的后面。
例文：友達に誘われたので、パーティーに行くには行くが、正直あまり気乗りはしない。

【〜とはいえ】
意味：虽说……但是……
接続：普通形
語感：承认前项事实，但后项是与常理不符的情况。
例文：医者だとはいえ、自分の病気はなかなかわからないものだ。

【〜といえども】
意味：即使是……也……
接続：名詞、普通形
語感：比とはいえ更书面、更郑重。
例文：いかなる理由があるといえども、暴力は許されない。

【〜であれ】
意味：就算是……也……
接続：名詞
語感：举出一个极端的例子，表示“即便是这样，也……”。
例文：たとえ国王であれ、法を破ることはできない。

【〜ものを】
意味：本来……可是……
接続：連体形
語感：与のに相近，但埋怨、不满、遗憾的语气更强烈。
例文：早く言えば手伝ってあげたものを。今からじゃ間に合わないよ。

【〜ないまでも】
意味：虽然到不了……的程度，但至少……
接続：動詞ない形
語感：表示退而求其次。
例文：毎日は無理ないまでも、週に一度は運動したい。

【〜ならまだしも】
意味：如果……的话还情有可原，可是……
接続：名詞、普通形
語感：表示前项还能接受，但后项更不能接受。
例文：１０分の遅刻ならまだしも、１時間も待たせるなんてひどい。

【〜たら〜たで】
意味：如果……的话，也自有……的（问题/办法）
接続：動詞た形＋ら＋動詞た形＋で
語感：表示无论发生或不发生某事，都会有相应的情况（通常是麻烦）。
例文：家は広かったら広かったで、掃除が大変そうだ。

【〜そうかと言って〜ない】

接続：普通形

【〜ものなら】

【〜ものとして】
意味：就当作……

語感：假定某事是事实，并在此基础上行动。
例文：契約は成立したものとして、作業を開始してください。

【〜とあれば】
意味：如果是为了……
接続：名詞、普通形

例文：子供のためとあれば、どんなことでも我慢できる。

【〜としたって / 〜にしたって】

例文：今から走っていったとしたって、もう間に合わないよ。

【〜としたところで / 〜にしたところで】

語感：和としたって相近，后项多为消极结果。

【〜たが最後 / 〜たら最後】

例文：彼は普段は無口だが、お酒が入るともなると、とてもおしゃべりになる。

【〜ようと〜ようと / 〜ようと〜まいと】

接続：動詞意向形

例文：他人がどう思おうと、私は自分の信じる道を進む。

【〜に即して】

【〜に引き換え】

【〜に関わりなく】

【〜にかけては】

【〜と相まって】

【〜をもって】

【〜をよそに】

【〜をものともせずに】

接続：名詞
語感：在困难、障碍面前毫不畏惧，毅然行动。赞扬人的精神和勇气。
例文：彼は体の障害をものともせずに、精力的に活動している。

【〜をこめて】
意味：饱含……地
接続：名詞
語感：强调动作中蕴含的深厚感情。

【〜を控えて】

接続：名詞

接続：名詞

【〜いかんだ・〜いかんによって】

接続：名詞
語感：表示结果由前项的情况来决定。

接続：名詞
語感：表示无论前项情况如何，结果都不变。

語感：表示某结果的主要原因或贡献者。
例文：今回の成功は、チーム全員の努力によるところが大きい。

【〜はおろか】
意味：别说A了，就连B也……

【〜もさることながら】

接続：名詞
語感：承认A很好/很突出，但更想强调B。

【〜言うに及ばず】
意味：……自不待言，……更不用说
接続：名詞
語感：和〜はもちろん意思相近，更书面。

【〜ならではの】

語感：1. 强调能力高超；2. 强调身兼二职。

【〜に〜を重ねる】
意味：一再地……，反复地……
接続：名詞
語感：强调动作或状态的反复。

【〜をおいて〜ない】
意味：除……之外，再无……
接続：名詞
語感：强调唯一性，带有极高的评价。

【〜てやまない】
意味：发自内心地……，一直……
接続：動詞て形

【〜たりとも】
意味：哪怕一……也（不）……
接続：数量詞（最小单位）
語感：与表示极小单位的词连用，后接否定，语气强烈。

【〜なり】
意味：哪怕……也行

【〜てまで】
意味：甚至不惜……也要……
接続：動詞て形
語感：表示为达目的做出极端行为。
例文：親に嘘をついてまで、遊びに行きたいとは思わない。

【〜からある】
意味：足有……，竟达……
接続：数量詞
語感：接在数量词后，表示数量之大，令人吃惊。
例文：彼は100キロからあるバーベルを軽々と持ち上げた。

【〜だに】
意味：光是……就……
接続：動詞辞書形

【〜すら・〜ですら】

【〜だけ】

【〜ただ〜のみ】

【〜だの〜だの】

接続：普通形
語感：列举事物，带有不满、厌烦的语气。

【〜なり〜なり】

【〜といい〜といい】

【〜つ〜つ】

【〜ときたら】

【〜とは】

【〜にあたらない】

例文：このような盛大な会にお招きいただき、光栄の至りです。

【〜嫌いがある】
意味：有……的（不好）倾向
接続：動詞辞書形、名詞＋の
語感：指出某种不太好的、习惯性的倾向。
例文：彼は物事を大げさに言うきらいがある。

【〜に足る】
意味：值得……
接続：動詞辞書形、する名詞
語感：表示有足够的价值做某事。
例文：彼の行動は、尊敬するに足るものだ。

【〜あるまじき】
意味：不应有的，不该做的
接続：名詞＋にあるまじき＋名詞
語感：从身份、立场出发，认为某种行为是绝对不该有的。
例文：学生にあるまじき行為をした者は、退学処分となります。

【〜というところだ】
意味：也就是……的程度，顶多……
接続：数量詞、名詞
語感：对数量、程度等做出一个不太高的、大致的评估。
例文：この仕事、給料はまあまあというところだ。

【〜ないものか】
意味：难道就不能……吗？
接続：動詞ない形
語感：强烈希望某件困难的事情能够实现。
例文：なんとかして、この危機を乗り越えられないものか。

【〜ずに済む】
意味：不用……就解决了
接続：動詞ない形（去掉ない）
語感：庆幸避免了做某件麻烦事。
例文：友達がお金を貸してくれたので、親に頼まずに済んだ。

【〜を禁じ得ない】
意味：禁不住……
接続：名詞
語感：书面语，表示某种情感或想法自然而然地涌现，无法抑制。
例文：彼の不幸な話を聞いて、涙を禁じ得なかった。

【〜を余儀なくされる / 〜を余儀なくさせる】
意味：被迫…… / 迫使……
接続：名詞
語感：非常正式的书面语，表示“迫不得已”。
例文：資金不足は、その工事の中止を余儀なくさせた。

【〜にたえる / 〜にたえない】
意味：值得…… / 不忍……，不堪……
接続：動詞辞書形、名詞
語感：表示是否值得做，或情感上能否承受。
例文：あの事件は聞くにたえないほど悲惨だった。

【〜べくもない】
意味：不可能……，无法……
接続：動詞辞書形
語感：书面语，表示由于条件、能力限制，完全没有可能性。
例文：素人の私には、その原因を知るべくもない。

【〜ずにはおかない】
意味：非要……不可，一定会……
接続：動詞ない形（去掉ない）
語感：客观力量导致必然结果，含有“势必会”的意思。
例文：彼の正直な発言は、波紋を呼ばずにはおかないだろう。

【〜てかなわない】
意味：……得受不了
接続：動詞て形、い/な形容詞
語感：表示某种（负面的）状态让人难以忍受。
例文：隣の工事がうるさくてかなわない。

【〜ともなく・〜ともなしに】
意味：无意中……，不经意地……
接続：動詞辞書形、疑問詞
語感：形容没有明确意识或目的的动作。
例文：電車の中で、ともなく外の景色を眺めていた。

【〜ことなく・〜ことなしに】
意味：不……，没……
接続：動詞辞書形
語感：书面语的「〜ないで」。
例文：彼は最後まであきらめることなく、戦い続けた。

【〜ごとき】
意味：像……一样；区区……（表轻蔑）
接続：名詞＋の
語感：1. 书面比喻。 2. 蔑视。
例文：山のごとき大男が現れた。

【〜ながらに】
意味：保持着……的状态
接続：名詞、動詞ます形
語感：表示某种天生或固有的状态一直持续。
例文：彼女は涙ながらに、別れを告げた。

【〜なりに】
意味：与相称地，以自己的方式
接続：名詞、普通形
語感：虽然有限制或不完美，但在那个范围内尽力了。
例文：下手は下手なりに、一生懸命歌った。

【〜ばかりになっている】
意味：一切准备就绪，只等……
接続：動詞辞書形・た形
語感：万事俱备，只欠东风。
例文：料理はもうできて、あとは食べるばかりになっている。

【〜とばかりに】
意味：就好像在说……一样
接続：発話内容＋とばかりに
語感：形容某种动作或表情，就好像在无声地表达某种强烈的意图或情感。
例文：「待ってました」とばかりに、彼は質問を始めた。

【〜んばかりに】
意味：简直就要……似的
接続：動詞ない形（する→せん）
語感：形容状态或样子的夸张程度，仿佛马上就要发生某事。
例文：彼女は、泣き出さんばかりの顔でこちらを見ていた。

【〜んがために】
意味：为了……
接続：動詞ない形（する→せん）
語感：书面语，强调为了某个重大目的。
例文：彼は自分の夢を実現せんがために、故郷を離れた。

【〜んとする】
意味：即将要……，正要……
接続：動詞ない形（する→せん）
語感：表示动作即将开始的瞬间。
例文：太陽が、まさに沈まんとしていた。

【〜べく】
意味：为了……
接続：動詞辞書形
語感：书面语，后接意志性动词，表示目的。
例文：約束の時間に間に合うべく、駅まで走った。

【〜べくして】
意味：注定地……，理所当然地……
接続：動詞辞書形＋べくして＋動詞た形
語感：强调结果的必然性。
例文：準備を怠ったのだから、負けるべくして負けたのだ。

【〜にあって】
意味：在……（这种特殊情况/环境下）
接続：名詞
語感：强调在某个特定的、非同寻常的状况下。
例文：この困難な状況にあって、彼は冷静さを失わなかった。

【〜そこなう】
意味：……失败，没能成功……
接続：動詞ます形
語感：表示想做但没做成，含有错失机会的遗憾。
例文：バスに乗り遅れて、約束の映画を見そこなった。

【〜こなす】
意味：熟练掌握……，圆满完成……
接続：動詞ます形
語感：强调能够灵活、熟练地驾驭。
例文：彼はどんな難しい役でも見事に演じこなす。

【〜あげる】
意味：……完成
接続：動詞ます形
語感：强调动作的彻底完成，作品的最终成型。
例文：彼は一晩でそのレポートを書き上げた。

【〜っぱなし】
意味：一直……（放任不管）
接続：動詞ます形
語感：多指本该改变的状态却一直保持原样，常带消极语感。
例文：彼はテレビをつけっぱなしにして寝てしまった。

【〜まみれ】
意味：沾满……，满是……
接続：名詞
語感：限于表面沾满了令人不快的东西（血、泥、汗、灰尘等）。
例文：泥まみれになってボールを追いかけた。

【〜ずくめ】
意味：全是……，清一色……
接続：名詞
語感：指全部都是某种状态或事物（如黑、好事、坏事等）。
例文：今年はいいことずくめの一年だった。

【〜にもほどがある】
意味：……也要有个限度
接続：動詞辞書形、い/な形容詞、名詞
語感：带有强烈的责备、不满语气。
例文：いくら親しいからって、冗談にもほどがある。

【〜にかまけて】
意味：只顾着……，专心于……（而忽略了其他）
接続：名詞
語感：因为过度专注于某事，导致疏忽了本来该做的事。
例文：仕事にかまけて、家族サービスを怠っている。

【〜にかこつけて】
意味：借口……，托辞……
接続：名詞
語感：以某事为表面理由，实际上是为了做别的事。
例文：彼は病気にかこつけて、面倒な会議を欠席した。
